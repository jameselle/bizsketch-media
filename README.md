# bizsketch-media

Temporary public media host for [@bizsketch](https://www.instagram.com/bizsketch/) Business Stick Explainer Reels.

Instagram's API publishes a video by fetching it from a URL with no authentication, so an episode is attached
to the `media` release here just long enough to post it:

    https://github.com/jameselle/bizsketch-media/releases/download/media/<filename>

Once the post is live and read back from Instagram, the file is deleted from the release. Nothing stays here
after it has been published, and nothing here may carry any company's data.
